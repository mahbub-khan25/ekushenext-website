    শুরু করার আগেBefore you start#

    একুশে নেক্সট একটি বাংলা কিবোর্ড। আপনি ইংরেজি অক্ষরে উচ্চারণ অনুযায়ী লেখেন (যেমন amar sonar bangla), আর একুশে সেটাকে সঠিক বানানে বাংলা করে দেয় (আমার সোনার বাংলা)। এর নিজস্ব অভিধান আছে, যেটা বাংলা একাডেমির প্রমিত বানান আগে দেখায়। সবকিছু আপনার কম্পিউটার বা ফোনেই চলে; ইন্টারনেট লাগে না, আর আপনার লেখা কোথাও পাঠানো হয় না।

    Ekushe Next is a Bangla keyboard. You type the way a word sounds, in English letters (say amar sonar bangla), and Ekushe writes it in correctly spelled Bangla (আমার সোনার বাংলা). It has its own dictionary, which puts the Bangla Academy standard spelling first. Everything runs on your own computer or phone: no internet is needed and nothing you type is sent anywhere.

    ইনস্টলInstall#

    ফাইলগুলো পাবেন এই সাইটের ডাউনলোড অংশে, অথবা সরাসরি GitHub-এর রিলিজ পাতায়। সেখানে সব সময় সর্বশেষ সংস্করণই থাকে। আপনার কম্পিউটারের জন্য কোন ফাইল, তা নিচে দেওয়া আছে।

    Get the files from the download section of this site, or straight from the releases page on GitHub; it always has the newest version. Which file you need is listed below.

    Windows

    ফাইলFileকখন নেবেনWhen to use it

    Ekushe-Setup.zipব্রাউজার .exe ডাউনলোড আটকে দিলে। ভেতরে একই Setup.exe।If your browser blocks the .exe. The same Setup.exe, zipped.
    Ekushe-Portable.exeইনস্টল না করে চালাতে চাইলে, যেমন অফিসের কম্পিউটারে বা পেনড্রাইভে। নিজে থেকে উইন্ডোজের সাথে চালু হয় না।To run it without installing, say on a work computer or from a USB stick. It doesn’t start with Windows on its own.
    Ekushe-Developer-Tools-x64.zipশুধু পরীক্ষক ও ডেভেলপারদের জন্য: পরীক্ষামূলক উইন্ডোজ ইনপুট মেথড (ekushe_tsf.dll) আর কমান্ড-লাইন টুল (ekushe-cli.exe)। সাধারণ ব্যবহারে লাগে না। beta.12 পর্যন্ত এর নাম ছিল Ekushe-Extras-x64.zip।For testers and developers only: the experimental Windows input method (ekushe_tsf.dll) and the command-line tool (ekushe-cli.exe). Not needed for everyday use. Up to beta.12 it was called Ekushe-Extras-x64.zip.
    1. Setup চালানডাউনলোড করা Ekushe-Setup.exe-এ ডাবল-ক্লিক করুন।
    2. Run the installerDouble-click the Ekushe-Setup.exe you downloaded.
    3. উইন্ডোজের সতর্কবার্তা পার হননীল “Windows protected your PC” বার্তা দেখালে More info চাপুন, তারপর Run anyway। প্রকাশকের নাম A S M Mahbub Afzal Khan দেখাবে। অ্যাপটি ডিজিটালি সাইন করা; সার্টিফিকেট নতুন বলে SmartScreen এখনো এটিকে চেনে না।
    4. Get past the SmartScreen warningIf a blue “Windows protected your PC” box appears, click More info, then Run anyway. The publisher shown should be A S M Mahbub Afzal Khan. The app is code-signed; the certificate is new, so SmartScreen doesn’t know it yet.
    5. বিকল্প বেছে নিনইনস্টলারে দুটি বিকল্প থাকে: ডেস্কটপ ও স্টার্ট মেনুতে শর্টকাট আর উইন্ডোজ চালু হলে সিস্টেম ট্রে-তে সক্রিয় রাখুন। দুটোই চালু রাখা ভালো। তারপর এক ক্লিকে ইনস্টল ও চালু করুন চাপুন।
    6. Choose the optionsThe installer has two options: Desktop & Start Menu shortcuts and Auto-Start in System Tray. Leaving both on is best. Then click Install & Launch.
    7. তৈরি“অভিনন্দন” বার্তা দেখালে একুশে চালু হয়ে গেছে। টাস্কবারের ডান কোণে (ঘড়ির পাশে) একুশের আইকন দেখবেন।
    8. DoneWhen you see the “congratulations” message, Ekushe is running. Its icon sits at the right end of the taskbar, next to the clock.

    একুশে ইনস্টল হয় %LOCALAPPDATA%\Programs\Ekushe ফোল্ডারে, তাই অ্যাডমিন পাসওয়ার্ড লাগে না। ইনস্টলে সমস্যা হলে কী কী হয়েছিল তা লেখা থাকে %TEMP%\ekushe-install.log ফাইলে; সমস্যা জানানোর সময় ফাইলটি জুড়ে দিন।

    Ekushe installs into %LOCALAPPDATA%\Programs\Ekushe, which is why no admin password is needed. If installing goes wrong, each step is recorded in %TEMP%\ekushe-install.log; please attach that file when you report the problem.

    5. ইনস্টলার শেষ করুনইনস্টলার একুশেকে /Library/Input Methods-এ রাখে আর আপনার ইনপুট সোর্সে যোগ করে দেয়।

    Unzip it and move Ekushe.app into ~/Library/Input Methods (in Finder, press ⇧⌘G and type that path). Log out and back in, then add the input source as described in First-time setup.

    Linux

    একুশে লিনাক্সে একটি IBus কিবোর্ড। আপনার ডিস্ট্রিবিউশন অনুযায়ী ফাইল বেছে নিন। টার্মিনালে যে ফোল্ডারে ফাইলটি ডাউনলোড হয়েছে সেখানে গিয়ে (সাধারণত cd ~/Downloads) কমান্ডটি চালান।

    On Linux, Ekushe is an IBus keyboard. Pick the file for your distribution. In a terminal, go to the folder you downloaded it to (usually cd ~/Downloads) and run the command.

    Ubuntu, Debian, Linux Mint, Pop!_OS (.deb)

    sudo apt install ./ekushe_*_amd64.deb

    Fedora, RHEL, openSUSE (.rpm)

    sudo dnf install ./ekushe-*.x86_64.rpm

    openSUSE-এ dnf-এর বদলে sudo zypper install ./ekushe-*.x86_64.rpm চালান।

    On openSUSE, use sudo zypper install ./ekushe-*.x86_64.rpm instead of dnf.

    যেকোনো ডিস্ট্রিবিউশনAny distribution (AppImage)

    chmod +x Ekushe-*-x86_64.AppImage
./Ekushe-*-x86_64.AppImage --install-keyboard

    IBus শুধু পুরো কম্পিউটারের জন্য ইনস্টল করা কিবোর্ড চেনে, তাই --install-keyboard একবার আপনার পাসওয়ার্ড চাইবে। শুধু স্টুডিও দেখতে চাইলে কিছু ইনস্টল না করেই AppImage-এ ডাবল-ক্লিক করুন।

    IBus only loads keyboards installed for the whole computer, so --install-keyboard asks for your password once. To just try Studio without installing anything, double-click the AppImage.

    উইন্ডোজে আলাদা করে কিছু যোগ করতে হয় না। ইনস্টলের পর একুশে টাস্কবারের ট্রে-তে বসে থাকে, আর আইকনে লেখা থাকে আপনি এখন কোন ভাষায় লিখছেন: বাং মানে বাংলা, EN মানে ইংরেজি।

    1. আইকনটি খুঁজুনঘড়ির পাশে না দেখলে ছোট ^ তীরচিহ্নে ক্লিক করুন; লুকানো আইকনগুলো সেখানে থাকে। সব সময় দেখতে চাইলে আইকনটি টেনে টাস্কবারে নামিয়ে আনুন।

    3. যেকোনো অ্যাপে লিখুনNotepad বা Word খুলুন, Shift দুবার দ্রুত চাপুন (বাংলা চালু হবে), তারপর ami banglay gan gai লিখে দেখুন।

    বাংলা ⇄ ইংরেজি বদলানোSwitching between Bangla and English#

    সবচেয়ে সহজ উপায়, সব কম্পিউটারেই: Shift দুবার দ্রুত চাপুন (মাঝে অন্য কোনো কী না চেপে)। একবার বাংলা, আবার চাপলে ইংরেজি। Shift অন্য কোনো শর্টকাটের সাথে মেলে না, তাই কোনো অ্যাপের কাজে বাধা দেয় না।

    The easiest way, on every computer: tap Shift twice quickly, with no other key in between. Once for Bangla, again for English. A double Shift tap isn’t a shortcut in any app, so it never gets in the way.

    Windows

    • অন্য কী পছন্দ হলে: স্টুডিওর সেটিংস বা ট্রে মেনু থেকে Ctrl+Space, F12 (পুরনো অভ্রের মতো) বা Ctrl+Alt+B বেছে নিতে পারেন।
    • Prefer another key? In Studio’s settings or the tray menu you can choose Ctrl+Space, F12 (as in classic Avro) or Ctrl+Alt+B.
    • মাউস দিয়ে: ট্রে আইকনে একবার ক্লিক করুন।
    • With the mouse: click the tray icon once.
    • বদলানোর সময় স্ক্রিনে ছোট একটি ব্যাজ দেখায় (যেমন “বাং · বাংলায় লিখছেন”), আর ট্রে আইকনও বদলে যায়।
    • Each switch shows a small badge on screen (such as “বাং · বাংলায় লিখছেন”), and the tray icon changes too.

    macOS

    • দুবার Shift একুশে চালু রেখেই ইংরেজিতে যায় আর ফেরে। ইনপুট মেনুতে এর অবস্থা লেখা থাকে (“Type English for now” / “Back to Bangla”)।
    • Double-tap Shift goes to English and back while Ekushe stays the input source. The input menu shows which one is on (“Type English for now” / “Back to Bangla”).
    • অন্য কিবোর্ডে যেতে macOS-এর নিজের উপায়: Control+Space, 🌐 কী, বা মেনু বারের ইনপুট মেনু।
    • To change keyboards, use macOS’s own switch: Control+Space, the 🌐 key or the input menu in the menu bar.
    • ম্যাকে একুশের ভেতরে বদলানোর জন্য শুধু দুবার Shift কাজ করে। সেটিংসে অন্য কী বেছে নিলে দুবার Shift বন্ধ হয়ে যায়, তখন macOS-এর ইনপুট সোর্স বদলেই কাজ সারুন।
    • On a Mac, only double-tap Shift switches inside Ekushe. Choosing another key in Settings turns double-tap Shift off; then simply switch input sources with macOS’s own keys.

    Linux

    • দুবার Shift একুশে চালু রেখেই ইংরেজিতে যায় আর ফেরে। IBus মেনুর Bangla ⇄ English দিয়েও হয়।

    • To change keyboards, press Super+Space (GNOME) or your desktop’s input switch key.
    • লিনাক্সেও একুশের ভেতরে বদলানোর জন্য শুধু দুবার Shift কাজ করে; সেটিংসে অন্য কী বেছে নিলে এটি বন্ধ হয়।

    কোন অ্যাপে কোন ভাষা, একুশে মনে রাখেEkushe remembers the language for each app

    উইন্ডোজ আর ম্যাকে একুশে মনে রাখে কোন অ্যাপে শেষবার কোন ভাষায় লিখছিলেন। যেমন Word-এ বাংলা আর ব্রাউজারে ইংরেজি রাখলে, অ্যাপ বদলালেই ভাষাও নিজে থেকে বদলে যাবে। টার্মিনাল (উইন্ডোজে Windows Terminal, Command Prompt, PowerShell; ম্যাকে Terminal, iTerm) ইংরেজিতে শুরু হয়, যাতে কমান্ড লিখতে ঝামেলা না হয়; দরকার হলে সেখানে দুবার Shift চেপে বাংলা লিখতে পারেন, একুশে সেটাও মনে রাখে। এটা না চাইলে সেটিংসে টার্মিনালে ইংরেজি বন্ধ করুন। লিনাক্সে ভাষা সব অ্যাপে একই থাকে।

    On Windows and Mac, Ekushe remembers which language you last used in each app. Keep Word in Bangla and your browser in English, and the language follows you as you switch apps. Terminals (Windows Terminal, Command Prompt and PowerShell on Windows; Terminal and iTerm on a Mac) start in English so commands aren’t mangled; double-tap Shift there if you do want Bangla, and Ekushe remembers that too. Don’t want this? Turn off English in terminals. On Linux, the language is the same in every app.

      ফোনেটিক নিয়মPhonetic reference#

      নিয়মগুলো অভ্রের মতোই, তাই অভ্রে অভ্যস্ত হলে নতুন কিছু শিখতে হবে না। তবে সব নিয়ম মুখস্থ রাখার দরকারও নেই: একুশের অভিধান কাছাকাছি বানান থেকেও সঠিক শব্দ খুঁজে নেয় (যেমন bhalo → ভালো, shohid → শহীদ)। নিচের তালিকা কাজে লাগে নাম, নতুন শব্দ বা অভিধানে নেই এমন কিছু লেখার সময়।

      The rules are the same as Avro’s, so if you know Avro there’s nothing new to learn. You don’t need to memorise them either: Ekushe’s dictionary finds the right word from a near spelling (bhalo → ভালো, shohid → শহীদ). The tables below help with names, new words and anything the dictionary doesn’t know.

      বড় হাতের আর ছোট হাতের অক্ষর আলাদা। t = ত কিন্তু T = ট; n = ন কিন্তু N = ণ। শব্দের শুরুতে বড় হাতের অক্ষর (যেমন বাক্যের শুরুতে Ami) সাধারণ শব্দে সমস্যা করে না, অভিধান ঠিক শব্দটিই দেখায়।

      Capital and small letters are different. t is ত but T is ট; n is ন but N is ণ. A capital at the start of a sentence (Ami) is fine for ordinary words; the dictionary still shows the right one.

      উল্টো দিকেও সাহায্য: পপ-আপের টিপHelp the other way round: tips in the popup

      ধরুন লিখলেন hese, আর যে শব্দটি চাইছিলেন (হেঁসে) তালিকায় তিন নম্বরে। তখন পপ-আপের সংকেতের সারিতে সবার আগে সবুজ রেখায় ঘেরা একটি টিপ দেখাবে: হেঁসে he^se। পরের বার সরাসরি he^se লিখলেই শব্দটি প্রথমে আসবে। চন্দ্রবিন্দু, খণ্ড-ত আর বিসর্গের জন্য এমন টিপ আসে, ছোট পপ-আপেও।

      Say you type hese, and the word you want (হেঁসে) is third in the list. The popup’s hint row then shows a tip first, outlined in green: হেঁসে he^se. Next time, type he^se and the word comes first. These tips appear for chandrabindu, khanda-ta and bisarga, even in the compact popup.

      সব চিহ্নের তালিকা এক জায়গায় আছে স্টুডিওর যুক্তবর্ণ গাইডের ওপরে; পপ-আপের সহায়িকা বোতাম সরাসরি সেখানে নিয়ে যায়।

      All the marks are listed together at the top of Studio’s conjunct guide; the popup’s সহায়িকা (Help) button takes you straight there.

      পরামর্শের পপ-আপThe suggestion popup#

      Windows

      উইন্ডোজে একুশের নিজের কাচের মতো পপ-আপ কার্সরের নিচে ভেসে ওঠে।

      On Windows, Ekushe’s own frosted-glass popup floats just below the text cursor.

      • পরামর্শের সারি: সবুজটি বাছাই করা, Space চাপলে সেটি বসবে। ইংরেজি শব্দও থাকতে পারে (যেমন amar), দরকার হলে Tab চেপে নিন বা ক্লিক করুন।
      • Suggestions: the green one is selected and Space places it. An English word can be on offer too (here amar); take it with Tab or a click.
      • সংকেতের সারি: এখন আর কোন অক্ষর লিখলে কোন কার, ফলা বা যুক্তবর্ণ হবে, তা দেখায়। যেমন amarw লিখলে র্ব। এই সারিতেই আগে আসে চিহ্নের টিপ।
      • Hints: which vowel sign, fola or conjunct the next letters would make, for example amarw → র্ব. Mark tips also appear first in this row.
      • যুক্তবর্ণ লুকান / দেখান: সংকেতের সারি লুকিয়ে পপ-আপ ছোট করে (ছোট পপ-আপ)। আবার চাপলে ফিরে আসে।
      • যুক্তবর্ণ লুকান / দেখান (hide / show conjuncts): hides the hint row for a smaller popup, and brings it back.
      • সহায়িকা: স্টুডিওর যুক্তবর্ণ ও চিহ্নের গাইড খোলে।
      • সহায়িকা (help): opens Studio’s conjunct and marks guide.

      পপ-আপের রং উইন্ডোজের অ্যাপ থিম (হালকা বা গাঢ়) অনুযায়ী বদলায়, আকার বদলায় স্ক্রিনের স্কেলিং অনুযায়ী। পেছনের ঝাপসা কাচের ভাবটি দেখাতে উইন্ডোজের Settings → Personalization → Colors → Transparency effects চালু থাকতে হবে। স্টুডিওর সেটিংসে স্বচ্ছতা ১০০% করলে পপ-আপ পুরো নিরেট হয়।

      The popup follows Windows’ app theme (light or dark) and your display scaling. The frosted blur behind it needs Settings → Personalization → Colors → Transparency effects turned on. Set the opacity to 100% in Studio’s settings for a fully solid popup.

      Chrome, Word-এর মতো কিছু অ্যাপ কার্সর কোথায় তা জানায় না; সেসব অ্যাপে পপ-আপ মাউসের কাছে দেখায়।

      Some apps, such as Chrome and Word, don’t report where the text cursor is; there the popup appears near the mouse instead.

      macOS · Linux

      ম্যাক আর লিনাক্সে পরামর্শ দেখায় সিস্টেমের নিজের পরামর্শ-বারে (macOS-এর candidate window, IBus-এর lookup table)। বাছাই করা শব্দটি লেখার জায়গায় দাগ দেওয়া অবস্থায় দেখা যায়; Space বসায়, Tab পরেরটিতে যায়। এর চেহারা সিস্টেমের থিম অনুযায়ী হয়, তাই স্টুডিওর স্বচ্ছতা বা ছোট পপ-আপের সেটিং এখানে প্রযোজ্য নয়।

      On a Mac and on Linux, suggestions appear in the system’s own candidate bar (macOS’s candidate window, IBus’s lookup table). The selected word shows underlined where you’re typing; Space places it and Tab moves to the next. It looks the way your system theme makes it, so Studio’s opacity and compact-popup settings don’t apply there.

      After you place a word, Ekushe guesses what may come next (“সকাল” or “জন্মদিন” after “শুভ”). It also learns the words you pick, so over time the suggestions start to match the way you write.

      অ্যান্ড্রয়েড কিবোর্ডThe Android keyboard#

      ফোনের একুশে নেক্সট কম্পিউটারের একই ইঞ্জিন আর অভিধান দিয়ে চলে, তাই ফোনেটিক নিয়ম, নির্দিষ্ট বানানের চিহ্ন, স্নিপেট সবই একই। নিচে শুধু ফোনের নিজস্ব জিনিসগুলো।

      Ekushe Next on a phone runs the same engine and dictionary as on a computer, so the phonetic rules, exact-spelling marks and snippets are all the same. Below are the things that are particular to the phone.

      কিবোর্ড এক নজরেThe keyboard at a glance

      • ওপরের সারি: লেখার সময় পরামর্শ, প্রথমটি সবুজ বা থিমের রঙে, যেটি Space চাপলে বসে। যেকোনোটায় চাপলে সেটা বসে, বেশি থাকলে আঙুলে সরিয়ে দেখুন। শব্দ বসানোর পর পরের শব্দের পরামর্শ আসে। কিছু না লিখলে এখানে বাংলা | EN সুইচ, ইমোজি, সেটিংস ⚙ আর কিবোর্ড লুকানোর ⌄ বোতাম থাকে।
      • The top strip: while you type, suggestions, the first in green (or your theme’s colour), which is what Space places. Tap any to place it; swipe for more. After a word, next-word suggestions appear. When you’re not typing, it holds the বাংলা | EN switch, emoji, settings ⚙ and ⌄ to hide the keyboard.
      • কীর কোণে বাংলা অক্ষর: প্রতিটি কী কোন বাংলা অক্ষর দেয় তা ছোট করে লেখা। Shift চাপলে বড় হাতের অক্ষরের বাংলা দেখায় (t → ত, T → ট)। সেটিংস থেকে বন্ধ করা যায়।
      • Bangla letters in the corners: each key shows the Bangla letter it types, small in the corner. With Shift on, they show the capital letter’s sound (t → ত, T → ট). You can turn them off in settings.
      • চেপে ধরুন: অক্ষর চেপে ধরলে বিকল্প আসে, আঙুল সরিয়ে বেছে নিন। যেমন t: T (ট), t`` (ৎ), th (থ); n: N (ণ), ng (ং), NG (ঞ); s: sh (শ), Sh (ষ); r: R (ড়), rr (রেফ), rri (ঋ)।
      • Press and hold: hold a letter for its choices, then slide to the one you want. For example t: T (ট), t`` (ৎ), th (থ); n: N (ণ), ng (ং), NG (ঞ); s: sh (শ), Sh (ষ); r: R (ড়), rr (রেফ), rri (ঋ).
      • কমা আর দাঁড়ি কী: কমা চেপে ধরলে ,, (হসন্ত), + (যুক্ত), ` (আলাদা) আর উদ্ধৃতিচিহ্ন; ফুলস্টপ চেপে ধরলে .. (বিন্দু), ^ (চন্দ্রবিন্দু), : (বিসর্গ), / (ইংরেজি শব্দ), $ (৳)।
      • Comma and full-stop keys: hold the comma for ,, (hasanta), + (join), ` (keep apart) and quotes; hold the full stop for .. (dot), ^ (chandrabindu), : (bisarga), / (English word) and $ (৳).
      • Space টেনে কার্সর সরান: Space-এ আঙুল রেখে বাঁয়ে-ডানে টানুন। দুবার Space চাপলে দাঁড়ি (।) বসে।
      • Slide on Space to move the cursor: keep a finger on Space and slide left or right. Double-tap Space for a dari (।).
      • ⌫ দিয়ে ফেরত: শব্দ বসানোর ঠিক পরে ⌫ চাপলে আপনার রোমান অক্ষরগুলো ফিরে আসে, আবার বেছে নিতে পারেন। ⌫ চেপে ধরলে একটানা মোছে।
      • ⌫ to undo: press ⌫ right after a word and your Roman letters come back to choose again. Hold ⌫ to keep deleting.
      • ?১২৩ সংখ্যা আর চিহ্ন, সেখান থেকে =\< আরও চিহ্ন। সংখ্যার ঘরে (ফোন নম্বর, পিন) নিজে থেকেই সংখ্যার কিবোর্ড আসে।
      • ?১২৩ for numbers and symbols, and =\< there for more. Number boxes (phone numbers, PINs) get a number pad by themselves.

      • বানান ঠিক করা: স্পষ্ট ভুল হলে Space চাপলেই ঠিক হয়: teh → the, dont → don’t, i → I। ঠিক পরেই ⌫ চাপলে আপনি যা লিখেছিলেন সেটা ফিরে আসে, আর সেটা আর বদলায় না। ফোনের নিজের বানান পরীক্ষক (সাধারণত Gboard বা Samsung-এর) চালু থাকলে তার পরামর্শও কাজে লাগে।
      • Spelling fixes: a clear typo is fixed when you press Space: teh → the, dont → don’t, i → I. Press ⌫ right after to get back what you typed, and it stays as it is. If the phone’s own spell checker is on (usually Gboard’s or Samsung’s), its suggestions are used too.
      • পরের শব্দ: শব্দের পর সাধারণ পরের শব্দের পরামর্শ আসে (thank → you), আর আপনি যেভাবে লেখেন তা থেকে শেখে।
      • Next word: after a word, common next words are suggested (thank → you), and it learns from the way you write.
      • শেখা: আপনি যে শব্দ বেশি লেখেন বা বেছে নেন, সেগুলো আগে আসে। ফোনের ব্যক্তিগত অভিধানের নামও চেনে।
      • Learning: words you write or pick often come first. Names in the phone’s personal dictionary are known too.

      গ্লাইড টাইপিং (আঙুল টেনে লেখা) বা ভয়েস টাইপিং চাইলে সেটিংসে ইংরেজির জন্য Gboard চালু করুন। পাসওয়ার্ড, ইমেইল আর ওয়েব ঠিকানার ঘরে কোনো পরামর্শ বা সংশোধন হয় না।

      একুশে স্টুডিওEkushe Studio#

      লেখার প্যাডWriting pad

      • আজকের তারিখ: inserts today’s date in Bangla.
      • দাড়ি ও ফাঁকা ঠিক করুন: ফুলস্টপকে দাঁড়ি করে আর বাড়তি ফাঁকা সরায়।

      গোপনীয়তা ও পাসওয়ার্ডPrivacy and password boxes#

      • কিছুই বাইরে যায় না। একুশে ইন্টারনেটে কিছু পাঠায় না; অভিধান, পরামর্শ, বানান পরীক্ষা সব আপনার কম্পিউটারেই চলে। স্টুডিও চলে শুধু আপনার কম্পিউটারের ভেতরের ঠিকানায় (127.0.0.1), এককালীন কোড দিয়ে।
      • Nothing leaves your computer. Ekushe sends nothing over the internet; the dictionary, suggestions and spell check all run locally. Studio runs only at your computer’s internal address (127.0.0.1), behind a one-time code.
      • পাসওয়ার্ডের ঘরে একুশে সরে দাঁড়ায়। পাসওয়ার্ড বা PIN-এর ঘরে সাধারণ অক্ষর বসে: কোনো বাংলা রূপান্তর নেই, পপ-আপ নেই, কিছু মনে রাখা হয় না।
      • Ekushe steps aside in password boxes. In a password or PIN field, plain characters are typed: no Bangla conversion, no popup, nothing remembered.
      • পাসওয়ার্ডের মতো দেখতে লেখা মনে রাখা হয় না, যেকোনো ঘরে: অক্ষর আর সংখ্যা মেশানো (abc123), @ # $ %-এর মতো চিহ্ন, বা খুব লম্বা টানা লেখা। সাধারণ শব্দ আর একুশের চিহ্ন (,, ^ rr …) আগের মতোই শেখা হয়।
      • Nothing that looks like a password is learned, in any field: letters mixed with digits (abc123), symbols such as @ # $ %, or very long unbroken strings. Ordinary words and Ekushe’s marks (,, ^ rr …) are learned as before.
      পাসওয়ার্ডের ঘর কীভাবে চেনেHow password boxes are recognised

In browsers it takes a moment after you click into the field; typing straight away usually works. If you ever see Bangla in a password box, double-tap Shift for English and type it again.
      macOSmacOS নিজেই পাসওয়ার্ডের ঘর থেকে সব কিবোর্ড ইনপুট মেথড সরিয়ে রাখে।macOS itself keeps input methods out of password fields.
      Linuxঘরটি নিজেকে পাসওয়ার্ড বা PIN, অথবা “private” বলে জানালে (GTK, Qt আর ব্রাউজার তা করে)।When the field says it is a password or PIN field, or marks itself “private” (GTK, Qt and browsers do).

      শেখা শব্দ মুছে নতুন করে শুরু করতে চাইলে একুশে বন্ধ রেখে সেটিংস ফোল্ডারের learned.tsv ফাইলটি মুছে দিন। ম্যাক আর লিনাক্সে সেটিংস ও শেখা শব্দের ফাইল শুধু আপনার নিজের অ্যাকাউন্ট পড়তে পারে।

      To forget the learned words and start fresh, close Ekushe and delete learned.tsv from the settings folder. On Mac and Linux, the settings and learned-word files are readable only by your own account.

      আপডেট ও আনইনস্টলUpdate and uninstall#

      একুশে নিজে থেকে আপডেট খোঁজে না। নতুন সংস্করণ এলে এই সাইটের ডাউনলোড অংশে পাবেন; আপনার সেটিংস, স্নিপেট আর শেখা শব্দ আপডেটের পরেও থেকে যায়।

      Ekushe doesn’t check for updates by itself. New versions appear in this site’s download section; your settings, snippets and learned words stay through updates.

      Windows

      আপডেটUpdate

      নতুন Ekushe-Setup.exe চালান। এটি চালু থাকা পুরনো একুশে বন্ধ করে নতুনটি বসিয়ে দেয়। পোর্টেবল ব্যবহার করলে পুরনো Ekushe-Portable.exe বন্ধ করে নতুন ফাইলটি দিয়ে বদলে দিন।

      Run the new Ekushe-Setup.exe. It stops the running Ekushe and puts the new one in its place. With the portable version, exit the old Ekushe-Portable.exe and replace it with the new file.

      আনইনস্টলUninstall

      Settings → Apps → Installed apps খুলুন, Ekushe Next Bangla Keyboard-এর পাশে ⋯ → Uninstall চাপুন। সেটিংসও মুছতে চাইলে এরপর %APPDATA%\Ekushe ফোল্ডারটি মুছুন।

      Open Settings → Apps → Installed apps and choose ⋯ → Uninstall next to Ekushe Next Bangla Keyboard. To remove your settings too, delete the %APPDATA%\Ekushe folder afterwards.

      আপডেটUpdate

      সমস্যা সমাধানTroubleshooting#

      অ্যান্ড্রয়েড: “App not installed” দেখাচ্ছেAndroid: it says “App not installed”

      সাধারণত ফোনে একুশে নেক্সটের আগের কোনো পরীক্ষামূলক (টেস্ট) সংস্করণ থাকলে এমন হয়, কারণ সেটি অন্য চাবিতে সাইন করা। আগেরটি আনইনস্টল করে নতুনটি ইনস্টল করুন। এরপর থেকে সব আপডেট সরাসরি ওপরে বসবে।

      This usually means an earlier test build of Ekushe Next is on the phone, signed with a different key. Uninstall that one, then install the new one. Every update after that installs straight over it.

      অ্যান্ড্রয়েড: EN চাপলে Gboard খোলে নাAndroid: EN doesn’t open Gboard

      ইংরেজি এখন নিজে থেকে একুশে নেক্সটেই লেখা হয়; Gboard চাইলে সেটিংসে ইংরেজির জন্য Gboard চালু করুন।

      English is now typed in Ekushe Next by default; for Gboard, turn on ইংরেজির জন্য Gboard in settings.

      Gboard ইনস্টল থাকলেও কিবোর্ড হিসেবে চালু থাকতে হয়। একুশে অ্যাপের ইংরেজির জন্য Gboard-এর নিচে Gboard চালু করুন চাপুন, অথবা Settings → System → Keyboard থেকে Gboard চালু করুন। Samsung-এর মতো যেসব ফোনে Gboard নেই, সেখানে Play Store থেকে Gboard নিন, অথবা এই সেটিং বন্ধ রেখে ইংরেজিও একুশেতে লিখুন।

      Gboard has to be turned on as a keyboard, not just installed. In the Ekushe app, tap Gboard চালু করুন under ইংরেজির জন্য Gboard, or turn Gboard on in Settings → System → Keyboard. On phones without Gboard, such as many Samsungs, get Gboard from the Play Store, or leave this setting off and type English in Ekushe.

      অ্যান্ড্রয়েড: ইংরেজিতে বানান ঠিক হচ্ছে নাAndroid: English spelling isn’t being fixed

      অ্যাপের ইংরেজি অটোকারেক্ট চালু আছে কি না দেখুন। একুশে শুধু স্পষ্ট ভুলই বদলায়; অচেনা নাম বা শব্দ যেমন লিখেছেন তেমনই থাকে। ফোনের বানান পরীক্ষক বন্ধ থাকলে (Settings → System → Languages → Spell checker) একুশে শুধু নিজের শব্দতালিকা দিয়ে কাজ করে।

      Check that ইংরেজি অটোকারেক্ট is on in the app. Ekushe only changes clear typos; names and words it doesn’t know stay as you typed them. If the phone’s spell checker is off (Settings → System → Languages → Spell checker), Ekushe uses its own word list only.

      অ্যান্ড্রয়েড: Gboard থেকে একুশেতে ফিরতে পারছি নাAndroid: I can’t get back from Gboard

      Gboard-এ 🌐 বোতাম না দেখালে তার Space চেপে ধরুন, কিবোর্ড বাছাইয়ের তালিকা আসবে; একুশে নেক্সট বেছে নিন। 🌐 বোতাম সবসময় দেখাতে Gboard-এর সেটিংসে Preferences → Show language switch key চালু করুন।

      If Gboard shows no 🌐 key, press and hold its space bar to open the keyboard picker and choose Ekushe Next. To always show the 🌐 key, turn on Preferences → Show language switch key in Gboard’s settings.

      উইন্ডোজ: ট্রে আইকন দেখছি নাWindows: I can’t see the tray icon

      ঘড়ির পাশের ^ তীরচিহ্নে দেখুন। সেখানেও না থাকলে একুশে চলছে না: Start Menu থেকে Ekushe Next Bangla Keyboard চালু করুন। প্রতিবার উইন্ডোজ চালুর সময় নিজে থেকে চালু চাইলে Setup আবার চালিয়ে “Auto-Start” বিকল্পটি চালু রাখুন।

      Check behind the ^ arrow next to the clock. If it isn’t there either, Ekushe isn’t running: start Ekushe Next Bangla Keyboard from the Start Menu. To have it start with Windows, run Setup again with “Auto-Start” switched on.

      উইন্ডোজ: কোনো একটি অ্যাপে বাংলা আসছে নাWindows: Bangla doesn’t work in one app

      অ্যাডমিন হিসেবে চালানো অ্যাপে (যেমন “Run as administrator” দিয়ে খোলা টার্মিনাল) উইন্ডোজ সাধারণ অ্যাপকে লিখতে দেয় না; তখন একুশে একটি বার্তা দেখায়: “এই উইন্ডোতে লেখা পাঠানো যায়নি”। অ্যাপটি সাধারণভাবে খুলুন। টার্মিনালে একুশে ইচ্ছা করেই ইংরেজিতে শুরু হয়; সেখানে দুবার Shift চাপুন।

      Windows doesn’t let ordinary apps type into apps running as administrator (say, a terminal opened with “Run as administrator”); Ekushe then shows a message saying it couldn’t send text to that window. Open the app normally. Terminals start in English on purpose; double-tap Shift there.

      উইন্ডোজ: পপ-আপ ভুল জায়গায় দেখায়Windows: the popup shows up in the wrong place

      Chrome, Word-এর মতো কিছু অ্যাপ কার্সরের অবস্থান জানায় না, তাই সেখানে পপ-আপ মাউসের কাছে আসে। লেখায় কোনো সমস্যা হয় না। চাইলে মাউস লেখার কাছে রাখুন, বা ছোট পপ-আপ চালু করুন।

      Some apps, such as Chrome and Word, don’t report the cursor position, so the popup appears near the mouse. Typing still works fine. Keep the mouse near your text, or switch on the compact popup.

      উইন্ডোজ: ইনস্টল হচ্ছে না বা মাঝপথে থেমে গেলWindows: the installer fails or stops halfway

      ব্রাউজার .exe আটকালে Ekushe-Setup.zip নিন। অ্যান্টিভাইরাস আটকালে ফাইলটি অনুমতি দিন (সাইন করা প্রকাশক: A S M Mahbub Afzal Khan)। তারপরও না হলে %TEMP%\ekushe-install.log ফাইলের শেষ কয়েকটি লাইন রিপোর্টে বসিয়ে আমাদের জানান।

      If your browser blocks the .exe, get Ekushe-Setup.zip. If antivirus blocks it, allow the file (signed publisher: A S M Mahbub Afzal Khan). If it still fails, report it, pasting the last lines of %TEMP%\ekushe-install.log into the report.

      ম্যাক: ইনপুট সোর্সের তালিকায় Ekushe Bangla নেইMac: Ekushe Bangla isn’t in the input source list

      একবার লগ আউট করে আবার ঢুকুন, তারপর Keyboard → Text Input → Edit… → +-এ Bengali-র নিচে দেখুন। তবুও না পেলে দেখুন /Library/Input Methods-এ Ekushe.app আছে কি না; না থাকলে .pkg আবার চালান।

      Log out and back in, then look under Bengali in Keyboard → Text Input → Edit… → +. If it still isn’t there, check that Ekushe.app is in /Library/Input Methods; if not, run the .pkg again.

      ম্যাক: “cannot be opened because it is from an unidentified developer”Mac: “cannot be opened because it is from an unidentified developer”

      System Settings → Privacy & Security-এ নিচে গিয়ে Open Anyway চাপুন। ইনস্টলারটি এখনো অ্যাপলের নোটারাইজেশন পায়নি, তাই এই ধাপটি একবার লাগে।

      Go to System Settings → Privacy & Security, scroll down and click Open Anyway. The installer isn’t notarized by Apple yet, so this step is needed once.

      লিনাক্স: Input Sources-এ একুশে দেখাচ্ছে নাLinux: Ekushe doesn’t show up in Input Sources

      ibus restart চালান বা লগ আউট করে আবার ঢুকুন। IBus চলছে কি না দেখতে ibus list-engine | grep -i ekushe চালান। কিছু না দেখালে প্যাকেজটি আবার ইনস্টল করুন (AppImage হলে --install-keyboard)। IBus না থাকলে আগে ইনস্টল করুন: sudo apt install ibus বা sudo dnf install ibus।

      Run ibus restart, or log out and back in. To check, run ibus list-engine | grep -i ekushe. If nothing shows, reinstall the package (or run the AppImage with --install-keyboard). If IBus itself is missing, install it first: sudo apt install ibus or sudo dnf install ibus.

      লিনাক্স: একটি অ্যাপে Backspace দিয়ে ফেরানো কাজ করে নাLinux: Backspace-undo doesn’t work in one app

      এর জন্য অ্যাপকে কার্সরের আশেপাশের লেখা জানাতে হয়। GTK আর Qt অ্যাপ তা করে, কিছু টার্মিনাল ও পুরনো অ্যাপ করে না। সেখানে সাধারণ Backspace দিয়ে মুছে আবার লিখুন।

      This needs the app to share the text around the cursor. GTK and Qt apps do; some terminals and older apps don’t. There, delete with ordinary Backspace and type the word again.

      স্টুডিও বলছে “একুশের মেনু থেকে খুলুন”Studio says to open it from Ekushe’s menu

      এটা নিরাপত্তার জন্য: পুরনো বুকমার্ক বা ইতিহাস থেকে খোলা পাতা আপনার সেটিংস দেখতে পারে না। একুশের মেনু (উইন্ডোজে ট্রে আইকন, ম্যাকে ইনপুট মেনু, লিনাক্সে IBus মেনু বা অ্যাপের তালিকা) থেকে আবার খুলুন।

      That’s for safety: a page opened from an old bookmark or your history can’t see your settings. Open it again from Ekushe’s menu (the tray icon on Windows, the input menu on a Mac, the IBus menu or applications menu on Linux).

      যে বানান চাই সেটা প্রথমে আসছে নাThe spelling I want doesn’t come first

      Tab চেপে সেটি বেছে নিন; একুশে মনে রাখবে, পরের বার আগে দেখাবে। চিহ্নযুক্ত শব্দ হলে পপ-আপের টিপ দেখুন, বা চিহ্ন দিয়ে লিখুন (he^se)। ঠিক যা টাইপ করছেন তা-ই আগে চাইলে সেটিংসে টাইপিং মোড ফোনেটিক আগে করুন।

      Pick it with Tab; Ekushe remembers and offers it earlier next time. For a word with a mark, follow the popup’s tip or type the mark yourself (he^se). If you want the letters you typed to come first, set the typing mode to Phonetic first.

      ইংরেজি লিখতে গিয়ে বাংলা চলে আসছেI get Bangla when I meant English

      দুবার Shift চেপে ইংরেজিতে যান, অথবা একটি শব্দের জন্য সামনে / দিন। ভুল শব্দটি ঠিক পরেই Ctrl+Backspace (ম্যাকে Control+Delete) চেপে উল্টে দিতে পারেন।

      Double-tap Shift for English, or put / in front of a single word. Flip a word that came out wrong with Ctrl+Backspace (Control+Delete on a Mac) right after it.

      সমাধান না পেলে আমাদের জানান (একুশের মেনুর সমস্যা জানান থেকেও খোলা যায়): কোন কম্পিউটার ও সংস্করণ, কোন অ্যাপে লিখছিলেন আর কী টাইপ করেছিলেন, লিখে দিন।

      Still stuck? Report it (also from Report a problem in Ekushe’s menu) and say which computer and version, which app you were typing in, and what you typed.
